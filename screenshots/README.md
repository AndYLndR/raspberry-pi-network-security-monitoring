Only screenshots that provide portfolio value should be included.

Expected evidence:

```text
screenshots/
├── system/
│   ├── raspberry-pi-system-info.png
│   └── post-reboot-validation.png
├── security/

├── prometheus/

└── grafana/

```

Before publishing, verify that screenshots do not expose:

- passwords
- API tokens
- private keys
- `.env` contents
- unnecessary MAC addresses
- personal hostnames
- unrelated private device information
