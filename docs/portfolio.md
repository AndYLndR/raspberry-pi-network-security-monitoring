## Interview summary

A useful 30-second explanation:

> I built a Raspberry Pi 5 as a dedicated network security and monitoring node for my home lab. Pi-hole provides DNS filtering, NetAlertX discovers devices, Uptime Kuma checks availability, and Prometheus plus Node Exporter feed a Grafana dashboard with host metrics such as CPU, RAM, disk, temperature and network usage. I also hardened SSH, reduced service exposure with firewall rules, separated internal-only services from LAN-facing services, tested persistence after reboot and created validated recovery backups.
